AWS High Availability Web Application Deployment
Project Overview

This project demonstrates deployment of a Dockerized web application on AWS using high-availability architecture and CI/CD automation.

Technologies Used
AWS EC2
Application Load Balancer (ALB)
Target Groups
CloudWatch
AWS Certificate Manager (ACM)
Docker
GitHub Actions
Linux
DNS
HTTPS
Terraform Fundamentals
Architecture

User Browser
→ DNS
→ Application Load Balancer
→ Target Group
→ Healthy EC2 Instance
→ Docker Container
→ Web Application

Features
Dockerized application deployment
Automated CI/CD using GitHub Actions
HTTPS implementation using ACM
Health checks and traffic routing
Multi-instance high availability
CloudWatch monitoring and alarms
Infrastructure troubleshooting and recovery
Learning Outcomes
AWS infrastructure deployment
Load balancing concepts
SSL certificate management
Containerized application deployment
CI/CD automation
Infrastructure as Code fundamentals
